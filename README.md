# بوابة السندباد الداخلية — ملفات التصميم

البوابة الداخلية لموظفي شركة نافذة صحار للتجارة – السندباد (الوكيل الحصري لـ OPPEIN في سلطنة عُمان).

## محتويات الفولدر

| المسار | الوصف |
|---|---|
| `index.html` | الموقع كاملًا في ملف واحد (HTML + CSS + JavaScript)، بالعربية والإنجليزية، مع الوضع الفاتح والداكن |
| `assets/images/` | صور منتجات OPPEIN المستخدمة في الواجهة والبانرات (من sindbadom.com) |
| `assets/docs/` | المستندات المعتمدة التي تعرضها المكتبة (PDF) |
| `previews/` | لقطات للتصميم: كل الصفحات على الديسكتوب، والرئيسية على الجوال وبالإنجليزية |
| `design-tokens.css` | الألوان والخطوط والمقاسات الأساسية لاستخدامها في أي تطوير لاحق |

## التشغيل

افتح `index.html` عبر أي خادم محلي (وليس بالنقر المزدوج، حتى تعمل ملفات PDF والصور):

```bash
cd sindbad-portal-design
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

أو ارفع الفولدر كما هو على أي استضافة (Netlify أو Vercel أو سيرفر الشركة).

## الصفحات

الرئيسية · الأخبار · المكتبة · الأنظمة · اللوائح · المبيعات · الشركة · الطلبات · الهوية · إدارة المحتوى.
يمكن فتح أي صفحة مباشرة بإضافة اسمها للرابط، مثل `index.html#policies`.

## ما يحتاج ربطًا بخادم عند التطوير

في النسخة المنشورة على Claude تعمل هذه الأجزاء على قاعدة بيانات مدمجة. في هذا الفولدر تظهر كتصميم فقط:

- **الأخبار والإعلانات:** يظهر إعلان ترحيبي واحد كمثال.
- **إدارة المحتوى:** إضافة الأخبار والمستندات والأنظمة وموظف الشهر.
- **طلبات بريد الشركة ومتابعة حالتها.**
- **اسم الموظف وصورته:** تحتاج تسجيل دخول (مثل Microsoft 365 أو Google Workspace).

أما الحاسبات (الجزاءات، العمولة، موعد الإجازة)، وحالة الدوام، والبحث، والمكتبة، فتعمل كاملة داخل الملف.

## ملاحظات

- روابط Odoo وتطبيق الحضور والبريد غير مضبوطة بعد؛ تُضاف في مصفوفة `DEF_APPS` داخل `index.html`.
- الشعار في الهيدر مرسوم بـ SVG كنسخة مؤقتة؛ استبدله بملف الشعار الأصلي.
- كل الأرقام والقواعد مأخوذة من دليل الموظف العام (سبتمبر 2026) ودليل إجراءات المبيعات والتصميم.
